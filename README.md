# KeyLogger_py

**Description**  
A simple Python key-capture example for learning threading, keyboard input, and background processing. **Do NOT use this on devices you do not own or have permission for.**

**Important:** Misuse of this software to capture other people's input is illegal and unethical. This project is for study and experimentation **only**.

---

## Features

- Capture keyboard input with `pynput`.
- Store captured keys in a buffer (`keyText`).
- Background worker thread periodically processes the buffer.
- Example of sending buffered content via Gmail SMTP using an app-specific password.
